# AItelier: notes for agents

Electrobun 2 desktop app (Bun main process) + React/Vite in the webview.
Read `README.md` for structure and status, `docs/spec.md` for the product spec
(in Italian). The app was called Bottega until 0.1.0.

- Electrobun is NOT Electron: see `llms.txt`. The 2.x SDK lives in
  `.hutch/devkit` (generated by `electrobun prepare`, ignored by git).
- Keep the identifier `ch.dambox.bottega`, the GitHub repository `bottega` and
  the update URL in `electrobun.config.ts`: the data folder, the keychain
  entry and automatic updates of installed apps depend on them. Only the
  visible name is AItelier.
- Logic goes in `src/core`, which never imports Electrobun. `src/bun` is a thin
  shell; the RPC handlers live in `src/bun/handlers.ts` and are also used by
  `scripts/preview.ts`.
- The API key must never end up in the database, in the logs or in RPC
  responses to the webview. The webview only sees `sk-...abcd`.
- Styles are global (a library) and linked to projects through
  `thread_styles`. A schema change is a new entry in `MIGRATIONS`
  (`src/core/db.ts`) with a test that starts from the previous schema; at
  startup the app makes a backup before migrating.
- Interface text and error messages are in Italian, always saying what to do
  next.
- Before saying an interface change works: `bun run preview` and check it in
  the built-in browser (demo data, no key).
- Vite uses port 5291 (5173 is often taken by other projects) and the shell
  only uses it if AItelier's own Vite answers.
- `bun run check` must pass: typecheck, `oxlint --deny-warnings`, tests.
  Format with `oxfmt`.
- Releases: tag `vX.Y.Z` equal to `version` in `package.json`; the workflow
  `.github/workflows/release.yml` creates a draft release. Never publish it
  without David's go-ahead: once published, it reaches every installed app as
  an update. A local build (`bun run build`) waits while the development app
  is open, because it holds Electrobun's build lock.
- Commits follow Conventional Commits, written in Italian, with no AI
  attribution trailer.
